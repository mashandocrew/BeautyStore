# Beauty Ecommerce — Sistema de Seguimiento de Cotizaciones

Panel interno para el proyecto de e-commerce de cosmética (skincare, sérums, kits de regalo) en Argentina, con foco en abastecimiento mayorista entre CABA y Mendoza.

## Contenido

- **`index.html`** — Sistema de seguimiento y comparación de cotizaciones de proveedores. Funciona como página estática, sin backend ni build step.

## Uso

Abrí `index.html` en cualquier navegador, o publicalo con **GitHub Pages** (Settings → Pages → Deploy from branch `main`, carpeta `/root`) para tener una URL pública tipo `https://TU-USUARIO.github.io/beauty-ecommerce/`.
